## 已确认行为

- 模式全局记忆，默认简单；模式选择只在设置页，工具栏实时参数面板不增加模式切换。
- 简单模式只有内容帧率（跟随源 / 具体帧率）和空闲重绘（关闭 / 具体帧率）两项。
- 简单模式接管隐藏设置：不管理 RTSS，Front Edge，光标原始帧优先并补充，补充率对齐固定内容帧率；跟随源时补充 60 FPS；VRR 关闭；重复帧检测关闭。
- 高级模式六项同级：目标窗口帧率限制、内容帧率、光标刷新方式、VRR、重复帧检测、空闲重绘；删除此组内原“高级选项”容器。
- 设置页及实时参数面板都删除内容帧率的“自动”选项；保留光标补充率的“自动”。旧内容自动迁移为跟随源，不在切回高级时恢复。
- 保存高级字段，不因简单模式投影而覆盖。内容与空闲两项共享；回到高级恢复隐藏参数。默认内容 60、空闲 30 FPS 不变。
- 模式及刷新参数保存后在下次启动缩放或保存并重启时应用。空闲重绘沿用补帧禁用与内容上限约束。

## 验收矩阵

| 场景 | 预期 |
| --- | --- |
| 新配置、模式字段缺失或无效 | 模式默认简单；新配置内容 60、空闲 30 FPS，已有共享数值保留；模式可持久化 |
| 默认配置与多个应用配置 | 模式全局一致，各应用的内容/空闲数值独立 |
| 旧内容 Auto / Custom / Source | Auto 迁移 Source，另两类不改枚举含义；重载不恢复 Auto |
| 简单内容 N / 跟随源 | 光标补充分别为 N / 60 FPS；不读取未生效的旧内容数值作为源模式补充率 |
| 高级配置启用 VRR、RTSS、重复帧及自定义节奏/光标 | 简单运行遵循固定规则；高级原值仍在，切回恢复 |
| 简单修改内容或空闲，再切高级 | 共享修改保留，不被高级备份覆盖 |
| 连续切换、关闭重开设置页、重启应用 | 模式与所有保存值稳定；打开控件不会触发隐藏值回写 |
| 活跃缩放时从设置页切换模式 | 当前运行参数保持；下次缩放或保存并重启使用新模式 |
| 面板陈旧快照、页面同时编辑 | 无关字段保留，冲突按现有事务处理；简单保存不抹掉高级字段 |
| 简单界面与高级界面 | 简单只有两项；高级六项平级，无旧高级容器；工具栏参数面板没有模式选择 |
| 本地化与控件宽度 | 资源齐全、XAML/IDL 绑定一致；原 FPS 范围 15–360 不变 |
| 补帧、内容上限、光标补充 | 沿用既有运行约束；源码验证与真实显示/GPU 验收分别报告 |
